# Repository guidance

This is a public repository. Commit reusable source, synthetic test fixtures,
examples and documentation that applies to all users.

- Keep personal notes, chat handoffs, machine-specific instructions, robot
  configurations, credentials, controller captures and local acceptance reports
  outside the repository or under the ignored `.local/` directory. Never force-add
  these files. Use environment variables for secrets.
- Use placeholder paths and documentation addresses in public examples. Tests
  should generate synthetic data in temporary directories; do not commit customer
  backups, programs, logs or proprietary FANUC binaries.
- Keep generated bytecode, environments, build output and installed runtime files
  untracked. Review `git status` and the staged diff before committing, including
  any new binary files.
- Update the root `README.md` when installation, commands, supported capabilities
  or limitations change. Follow its standard-readme structure and link to `docs/`
  for detailed guides. Keep local testing narratives out of public documentation.
- Follow `CONTRIBUTING.md` for development and validation. Distinguish offline
  checks from controller acceptance; never infer native behavior from file
  transfer success alone.
- Follow `docs/CONNECTION_READINESS.md` when changing imports, tools, launchers or
  admission. Classify metadata versus data/native cost; verify cold saved-route
  startup, expected multi-chat demand and lifecycle behavior without retiring
  legitimate peers. Preserve failed cases and private evidence under `.local/`.
